# Shkala iOS - rules for Claude

- USER RULE: the Persian word «شکالا» must NEVER appear anywhere in the app UI. The store name is «سیما حفاظ خزر».
- Reply to the user in Persian. Code comments in Persian, matching the Android app's style.
- USER RULE: the iOS app is an EXACT copy of the Android app (repo alirezaatwo/shkala-android, Kotlin/Compose).
  Port each screen line by line from its Kotlin file: same layout, sizes (dp -> pt, sp -> pt), colors, texts,
  icons (RemixIcons names are identical), timings and behavior. Only OS-forced differences are allowed; list them.
- USER RULE (2026-11-07): EVERY change/update made to the Android app from now on must also be applied to iOS;
  iOS must never lack anything Android has. Always port against the latest shkala-android main (synced: 3.0 / code 21).
  When an Android PR merges, port it to iOS in a matching PR.
- USER RULE (2026-11-07): the iOS version always equals the Android version: project.yml MARKETING_VERSION = Android
  versionName, CURRENT_PROJECT_VERSION = Android versionCode (now 3.0 / 21). Bump both in every port PR.
- Names mirror Android: Color.kt -> ShkColors, MaterialTheme.colorScheme -> @Environment(\.shkColors),
  isAppInDarkTheme() -> @Environment(\.shkIsDark), RemixIcon(...) -> RemixIcon(...), Typography -> ShkTextStyle / .shkFont().
- Whole app is RTL (ShkalaTheme sets layoutDirection). Canvas/pager code that must not mirror forces .leftToRight locally.
- No Mac here: GitHub Actions (.github/workflows/ios-build.yml) is the compiler. Push, then read the run logs and the
  `screenshots` artifact. Screens for screenshots are selected with launch args `-shkScreen <name>` (see ScreenshotMode).
- Project file is generated by XcodeGen from project.yml; never commit .xcodeproj.
- Deployment target iOS 16. iPhone only. Build is unsigned (Iranian stores like Sibapp re-sign).
- API: same server API as Android (api_contract.md in project files); only add response keys, never rename/remove.
- RemixIcons.swift is generated: scripts/gen_remix_icons.py <android>/ui/common/icons/RemixIcons.kt
